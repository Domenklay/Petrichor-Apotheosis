# Changelog / История изменений

## 0.8.0 — Petrichor: Apotheosis

### English

- Renamed the public mod from **Petrichor Legacy** to **Petrichor: Apotheosis**.
- Preserved the legacy BepInEx GUID and save directory for 0.7.x save compatibility.
- Promoted the 0.7.1 progression redesign into the new repository baseline.
- Mastery class milestones use effective ranks and each discipline has 10/25/50/100 thresholds.
- Added automatic infinite Prestige every 100 meta-levels.
- Perfection uses the three-path Triumph / Endurance / Expedition constellation.
- Special-monster rarity weights scale upward with meta level.
- Special monsters use mechanical affixes, compact item/affix overhead UI and controlled affix combinations.
- Legacy early progression spans ten meaningful purchases before class development.
- Improved talent/capstone layout, icons and item-effect descriptions.

### Русский

- Публичное название изменено с **Petrichor Legacy** на **Petrichor: Apotheosis**.
- Старый BepInEx GUID и папка сохранений оставлены для совместимости с прогрессом 0.7.x.
- Переработка прогрессии из 0.7.1 стала новой базовой версией проекта.
- Общие рубежи Мастерства считаются по эффективным рангам, у каждой дисциплины есть пороги 10/25/50/100.
- Добавлен автоматический бесконечный Престиж каждые 100 мета-уровней.
- Совершенство построено как три направления: Триумф / Стойкость / Экспедиция.
- Вес высоких редкостей особых монстров растёт вместе с мета-уровнем.
- Особые монстры используют механические особенности, компактный UI предметов/аффиксов и ограничения несовместимых комбинаций.
- Раннее Наследие занимает десять содержательных покупок до развития класса.
- Улучшены раскладка талантов и капстоунов, иконки и описания эффектов легендарных предметов.

## Historical versions / Исторические версии

Development before 0.8.0 was maintained inside the `Domenklay/ForAi` working repository under the Petrichor Legacy name. The dedicated repository starts from the materialized 0.7.1 codebase and continues development as Petrichor: Apotheosis.

Разработка до 0.8.0 велась в рабочем репозитории `Domenklay/ForAi` под названием Petrichor Legacy. Отдельный репозиторий начинается с материализованного исходного кода 0.7.1 и продолжает развитие уже как Petrichor: Apotheosis.
