# Petrichor: Apotheosis

[English version](README.md)

**Petrichor: Apotheosis** — мод для **Risk of Rain 2** с постоянной мета-прогрессией между забегами. Он расширяет долгосрочное развитие персонажа, не заменяя основной roguelike-цикл игры.

> Текущая версия: **0.8.0** — публичное переименование Petrichor Legacy 0.7.1.

## Основные системы

- **Наследие** — первые десять мета-уровней формируют ранний путь развития до открытия классов.
- **7 классов** — Страж, Истребитель, Следопыт, Искатель, Арканист, Техномант и Командир.
- **21 специализация** — по три самостоятельные специализации для каждого класса.
- **Арсенал** — постоянный выбор стартовых предметов в пределах ограниченной вместимости. Финальные награды класса и специализации существуют отдельно и не занимают вместимость Арсенала.
- **Мастерство** — бесконечное классовое развитие с diminishing returns, личными порогами дисциплин и общими рубежами класса по эффективным рангам.
- **Совершенство** — долгосрочное дерево из трёх направлений: Триумф, Стойкость и Экспедиция.
- **Престиж** — автоматическая бесконечная прогрессия каждые 100 мета-уровней.
- **Особые монстры** — собственные редкости, безопасный пул предметов, компактные индикаторы и механические особенности, меняющие позиционирование, приоритет целей и тайминги боя.
- **Постоянный прогресс** — уровень, XP, таланты, Мастерство, Совершенство и выбор Арсенала сохраняются между забегами.

## Структура прогрессии

`Наследие (1–10) → Класс → Специализация → Мастерство (41+) → Совершенство (каждые 25 уровней) → Престиж (каждые 100 уровней) → ∞`

### Мастерство

У каждого класса четыре бесконечные дисциплины. Для сырых рангов действует снижение эффективности:

- 1–25: 100%
- 26–50: 75%
- 51–100: 50%
- 101–200: 30%
- 201+: 20%

У каждой дисциплины есть собственные пороги **10 / 25 / 50 / 100** рангов. Общие рубежи класса считаются по сумме **эффективных** рангов, поэтому залить всё в один показатель можно, но это больше не самый быстрый способ открыть все классовые награды.

### Совершенство

Каждые 25 уровней выдаётся одно очко Совершенства. Три направления можно смешивать:

- **Триумф** — боссы, особые враги и темп атаки.
- **Стойкость** — восстановление, барьеры и выживаемость.
- **Экспедиция** — Арсенал, мета-XP и экономика.

### Престиж

Престиж начисляется автоматически: каждые 100 мета-уровней дают один ранг. Цикл из пяти наград повторяется бесконечно и даёт умеренные долгосрочные бонусы к мета-XP за особых врагов, стартовому золоту, золоту с особых врагов, урону по боссам/особым врагам и редкому росту вместимости Арсенала.

## Особые монстры

Редкости особых монстров существуют отдельно от стандартного `EliteDef`. Высокие редкости получают больше боевых предметов и особенностей, но сложность специально смещена от огромных запасов HP к механикам: телепортам, отложенным атакам, поддержке группы, фазам защиты, барьерам и позиционным угрозам.

Интерфейс над врагом остаётся компактным: предметы и особенности показываются одним рядом маленьких значков/кодов с подсказками, без огромных блоков текста.

## Установка

1. Установить BepInEx 5 для Risk of Rain 2.
2. Скачать готовую сборку или собрать проект.
3. Скопировать папку `PetrichorApotheosis` в `BepInEx/plugins/`.
4. Запустить игру и нажать **M**, чтобы открыть интерфейс прогрессии.

Текущее целевое окружение:

- Risk of Rain 2 `1.5.0#1224`
- BepInEx `5.4.21`
- `RiskOfRain2.GameLibs 1.5.0-r.1`
- `MMHOOK.RoR2 2026.10.8`

R2API не требуется. Newtonsoft.Json добавляется в готовую сборку.

## Совместимость сохранений

Начиная с 0.8.0 публичное название изменено с **Petrichor Legacy** на **Petrichor: Apotheosis**.

Для совместимости внутренний BepInEx GUID намеренно остаётся:

`com.petrichorlegacy.metaprogression`

Старая папка сохранений `PetrichorLegacy` также сохраняется. Благодаря этому прогресс из версий 0.7.x должен продолжить загружаться после переименования.

## Мультиплеер

Слой мета-прогрессии пока авторитетен со стороны хоста/одиночной игры. Полная синхронизация отображения всех особенностей особых монстров для обычных клиентов остаётся отдельной будущей задачей.

## Сборка

```bash
dotnet restore src/PetrichorApotheosis/PetrichorApotheosis.csproj
dotnet build src/PetrichorApotheosis/PetrichorApotheosis.csproj -c Release --no-restore
```
